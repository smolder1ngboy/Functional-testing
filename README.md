Название: «Исчезновение ошибки при повторном вводе»

Шаги воспроизведения:
1. Ввести в поле ввода email «invalid-email»
2. Нажать кнопку «Проверить»
3. Получить ошибку красного цвета над кнопкой «Проверить» с текстом «Введен некорректный email»
4. Начать редактирование поля ввода email-адреса

Ожидаемый результат: при начале редактирования сообщение об ошибке исчезает
